# Crossways Family Dental — Vercel & GitHub Deployment Package

## Files to Upload to Your GitHub Repository Root
When you extract this ZIP file, upload these files directly to the root of your GitHub repository:
1. `index.html` (Required — contains the complete website, 3D experience, all 10 clinic photographs, and the hero walkthrough video embedded inside)
2. `vercel.json` (Recommended — configures Vercel routing so no URL ever returns a 404 error)
3. `assets/` (Optional backup folder containing the standalone MP4 video and 10 clinic photographs)

## Vercel Settings (Zero-Config Static Deployment)
- **Framework Preset:** `Other`
- **Root Directory:** `./` (default)
- **Build Command:** Leave blank / off
- **Output Directory:** Leave blank / default
